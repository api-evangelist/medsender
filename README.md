Medsender provides AI‑powered fax, referral management, and call automation solutions for healthcare practices. By automating front‑office communications, it helps clinics reduce patient wait times, improve referral conversion, and maintain HIPAA‑compliant, end‑to‑end encrypted data handling. The platform integrates with major EMR systems and offers a secure fax API, AI‑driven voice calling, and a referral leakage calculator to streamline administrative workflows.

**Areas:** Referral Management · Fax Automation · Patient Recapture · Call Automation · EHR Integration

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Medsender: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
